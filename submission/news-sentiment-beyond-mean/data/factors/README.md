# Fama–French daily factors

Public research factors from Kenneth R. French's data library, used only for the
Notebook 85 close-to-close residual sensitivity.

- Source: https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html
- Vendor file: `F-F_Research_Data_Factors_daily_CSV.zip`
- This copy: daily `Mkt-RF`, `SMB`, `HML` and `RF` from 2009-01-01 through 2020-02-28, stored as decimals
- Units in the vendor file are percent; the loader converts them before this CSV is written

These are not licensed news. Do not add Reuters or FNSPID text to this folder.
