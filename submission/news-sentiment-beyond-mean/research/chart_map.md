# Dissertation chart map

This map fixes each analytical question, chart form, unit and source before the
figure is rendered. The report uses vector PDF figures plus 300-dpi PNG review
snapshots, both sized to the A4 text block and inspected in the compiled report.
All eleven analytical figures use an editorial-atlas visual system: Avenir Next with a
portable sans-serif fallback, a white surface, midnight-blue primary marks,
copper comparison or cost marks, warm-grey scaffolding and direct labels.
Colour never carries meaning alone. Shape, fill, line style, ordering and panel
position repeat every distinction. The set deliberately varies chart grammar
to match the comparison rather than repeating one generic forest plot.

The LaTeX caption supplies each figure's neutral title, unit, time or cohort
context, sample size where relevant and aggregate source. Plot interiors contain
only panel labels, comparison labels and values needed to decode the evidence.

## Formatting references

- [Nature Research figure specifications](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/): final-size authoring, standard sans-serif labels, accessible colour, explicit units, minimal decorative scaffolding and editable vector export.
- [PLOS figure requirements](https://journals.plos.org/plosmedicine/s/figures): 8-point text, approximately 0.2 mm lines, final-dimension export and 300--600 dpi raster delivery.
- [Rougier, Droettboom and Bourne (2014)](https://doi.org/10.1371/journal.pcbi.1003833): adapt figures to the reading medium, label important values, avoid default styling and remove chartjunk that does not aid interpretation.
