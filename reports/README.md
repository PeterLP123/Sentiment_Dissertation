# Historical Reports

This directory preserves licence-safe reports and compact evidence from research that
preceded the submitted dissertation. The final claims and their authoritative evidence
map are in the
[`submission/news-sentiment-beyond-mean/`](../submission/news-sentiment-beyond-mean/README.md)
package.

| Contents | Purpose |
| --- | --- |
| Top-level Markdown reports | Human-readable records of model comparisons and trading studies |
| `data/` and `figures/` | Small published inputs and graphics used by those reports |
| `fnsipid_tail_risk_*` | Tail-risk run summaries, manifests, robustness checks, and the visual explainer |
| Dated pilot and loop directories | Historical run records with their declared samples and limitations |
| Dashboard HTML | Portable views generated from frozen or local result artifacts |

The repository intentionally omits licensed text and many large generated files. A
report may therefore refer to a local artifact that is unavailable in a fresh clone;
those references are labelled as such. Do not infer that an archived result is part of
the dissertation's final confirmatory evidence. See the
[research archive](../docs/research_archive.md) for the relationship between studies.
