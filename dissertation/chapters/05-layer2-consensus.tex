\section{Hypotheses}
\label{sec:l2-hypotheses}

As pre-registered (\cref{sec:data-rigor}):
\begin{itemize}
  \item \textbf{H2a (crowding/reversal):} post-news abnormal returns
        following high-agreement readings revert over $h = 1$--$10$
        days, increasingly so post-2023.
  \item \textbf{H2b (disagreement/drift):} low-agreement items show
        continued drift.
  \item \textbf{H2c (identification):} effects concentrate where
        machine consensus occurs \emph{despite} high textual
        ambiguity.
\end{itemize}
